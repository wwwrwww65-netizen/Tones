## 📌 1. نظرة عامة على المشروع (Overview)

هذا المجلد (`soma/`) يحتوي على **قالب متكامل واحترافي لصفحة تسجيل الدخول وبوابة المصادقة (Captive Portal)** المخصصة لخدمة الهوتسبوت (**MikroTik RouterOS Hotspot**)، المصممة خصيصاً لـ **شبكة سوما نت اللاسلكية**.

تم تصميم القالب ليعمل بشكل محلي ومستقل تماماً داخل ذاكرة راوتر مايكروتك دون الحاجة لاتصال خارجي بالإنترنت لجلب الخطوط أو الأيقونات أو ملفات الجافاسكريبت، مع دعم كامل للغة العربية، وتوافق مع الهواتف الذكية وأجهزة الحاسوب.

## ⚙️ 3. آلية الربط والتكامل مع مايكروتك (MikroTik Integration Engine)

يقوم راوتر مايكروتك (**MikroTik RouterOS**) بمعالجة ملفات الـ HTML عبر محرك قوالب داخلي (Template Engine) يستبدل المتغيرات المحصورة بين `$(...)` بالبيانات الفعلية للمشترك والسيرفر قبل إرسال الصفحة للمتصفح.

### 🏷️ جدول متغيرات مايكروتك المستخدمة في القالب:

| المتغير في القالب | الوصف والوظيفة |
| :--- | :--- |
| `$(link-login)` | رابط صفحة تسجيل الدخول (مثال: `http://10.0.0.1/login`). |
| `$(link-login-only)` | رابط إرسال بيانات النموذج (POST Target) لتسجيل الدخول مباشرة. |
| `$(link-logout)` | رابط إنهاء الجلسة وتسجيل الخروج من الهوتسبوت. |
| `$(link-status)` | رابط نافذة حالة الاتصال المنبثقة. |
| `$(link-orig)` | الرابط الأصلي الذي كان المستخدم يحاول فتحه قبل اعتراضه بواسطة البوابة. |
| `$(link-redirect)` | رابط التوجيه المحدد بعد تسجيل الدخول أو رابط الإعلان. |
| `$(username)` | اسم المستخدم الحالي أو رقم الكرت المدخل. |
| `$(ip)` | عنوان الـ IP المخصص لجهاز المشترك من الـ IP Pool. |
| `$(mac)` | العنوان الفيزيائي (MAC Address) لكرت شبكة جهاز المشترك. |
| `$(uptime)` | المدة الزمنية النشطة للجلسة الحالية. |
| `$(session-time-left)` | الوقت المتبقي في حساب المشترك (بتنسيق: `1w2d3h4m5s`). |
| `$(remain-bytes-total-nice)` | الرصيد المتبقي من حجم البيانات بصيغة مقروءة (مثل: `500 MB` أو `2 GB`). |
| `$(bytes-in-nice)` / `$(bytes-out-nice)` | حجم البيانات المحملة والمرفوعة. |
| `$(chap-id)` | معرف التحدي الفريد المولد من مايكروتك لكل محاولة تسجيل دخول. |
| `$(chap-challenge)` | السلسلة العشوائية المشفرة للتحدي (Hex String). |
| `$(error)` | نص رسالة الخطأ الواردة من السيرفر عند فشل تسجيل الدخول. |
| `$(error-orig)` | نص الخطأ الأصلي الصادر من نظام مايكروتك. |

### 🔀 الشروط المنطقية المعتمدة في مايكروتك:
يستخدم القالب وسوم الشروط التي يعالجها سيرفر مايكروتك:
- `$(if chap-id) ... $(endif)`: لتفعيل نموذج المصادقة المشفر في حال كان السيرفر يعمل ببروتوكول CHAP.
- `$(if error) ... $(endif)`: لإظهار صندوق التنبيه بالأخطاء عند وجود خطأ.
- `$(if login-by-mac != 'yes') ... $(endif)`: للتحقق مما إذا كان الدخول ليس عبر الماك أدرس فقط.
- `$(if session-time-left) ... $(endif)`: للتحقق من وجود رصيد وقت محدد وعرضه.
- `$(if advert-pending == 'yes') ... $(endif)`: لتشغيل نافذة الإعلانات الإجبارية.

## 🔐 4. دورة المصادقة وتسجيل الدخول (Authentication Flow)

يدعم القالب نوعين رئيسيين من عمليات المصادقة:

### 1️⃣ مصادقة HTTP-CHAP (الافتراضية والأكثر أماناً):
1. يرسل الراوتر كلاً من `$(chap-id)` و `$(chap-challenge)` داخل صفحة `login.html`.
2. يتم تفعيل كود الجافاسكريبت مع النموذج الخفي `sendin`:
   ```html
   <form name="sendin" action="$(link-login-only)" method="post">
       <input type="hidden" name="username" />
       <input type="hidden" name="password" />
       <input type="hidden" name="dst" value="$(link-orig)" />
       <input type="hidden" name="popup" value="true" />
   </form>
   ```
3. عند الضغط على زر "دخول"، يتم استدعاء دالة `doLogin()` في الجافاسكريبت:
   ```javascript
   function doLogin() {
       document.sendin.username.value = document.login.username.value;
       document.sendin.password.value = hexMD5('$(chap-id)' + document.login.password.value + '$(chap-challenge)');
       document.sendin.submit();
       return false;
   }
   ```
4. يتم تشفير كلمة المرور عبر دمج: `chap-id + password + chap-challenge` واستخراج الهاش عبر دالة `hexMD5` من ملف `md5.js`.
5. يستقبل الراوتر الهاش ويقارنه بالقيمة المحسوبة لديه دون أن تنتقل كلمة المرور مكشوفة عبر الشبكة.

### 2️⃣ نظام الدخول برقم الكرت فقط (Single PIN / Card Code):
تم تصميم واجهة القالب لشبكات البطاقات مسبقة الدفع (Hotspot Cards) حيث يحتوي حقل الإدخال على:
- حقل واحد لاسم المستخدم (رقم الكرت) مع معالجة تنظيف المسافات تلقائياً:
  ```html
  <input type="text" onblur="this.value=removeSpaces(this.value);" placeholder="أسم المستخدم" name="username" value="$(username)" required/>
  ```

## 🍪 5. إدارة الجلسات والكوكيز والتحويلات (Cookies & Redirection)

### 🍪 ملفات تعريف الارتباط (Cookies):
- **حفظ تسجيل الدخول (HTTP Cookie)**: عند تفعيل خاصية `Cookie` في الـ `Server Profile` بالمايكروتك، يتم حفظ كوكيز في متصفح المشترك لتسجيل دخوله تلقائياً عند إعادة الاتصال.
- **مسح الكوكيز عند تسجيل الخروج (`erase-cookie`)**: في صفحة `status.html`، يحتوي نموذج الخروج على:
  ```html
  <input type="hidden" name="erase-cookie" value="on">
  ```
  هذا الحقل بالغ الأهمية حيث يخبر مايكروتك بمسح الكوكيز المخزنة للماك أدرس حتى لا يتم إعادة إدخال المشترك تلقائياً بعد خروجه الإرادي.

### 🔄 مسارات التحويل والروابط (Redirection & Navigation Paths):
1. **التحويل بعد الدخول (`alogin.html`)**:
   - بعد نجاح عملية المصادقة، يتم تحويل المستخدم إلى `alogin.html`.
   - تقوم الصفحة بعد 4 ثوانٍ بتحويل المشترك إلى صفحة الحالة `status.html`:
     ```html
     <body onload="timer=setTimeout(function(){ window.location='status.html';}, 4000)">
     ```
2. **التحويل للموقع الأصلي (`dst=$(link-orig)`)**:
   - يتم إرسال الرابط الأصلي الذي طلبه المشترك في حقل `dst` لكي يفتح موقعه فور اكتمال الاتصال.
3. **نافذة الحالة المنبثقة (`popup=true`)**:
   - تتيح فتح نافذة صغيرة للمشترك لمراقبة استهلاك الوقت والرصيد طوال فترة تصفحه.
4. **صفحة إنهاء الجلسة (`logout.html`)**:
   - تعرض إشعار انتهاء الجلسة وزر "تسجيل الدخول" للعودة إلى `$(link-login)`.

## 📊 6. تحليل صفحة الحالة وتنسيق الوقت (`status.html`)

تتميز صفحة الحالة بعرض دقيق لبيانات الحساب:
1. **اسم المستخدم (`$(username)`)**: يعرض رقم الكرت النشط.
2. **الرصيد المتبقي (`$(remain-bytes-total-nice)`)**: يعرض كمية الميجابايت/الجيجابايت المتبقية في الحساب.
3. **تعريب الوقت المتبقي (`$(session-time-left)`)**:
   يقوم كود جافاسكريبت المرفق بتحويل رموز الوقت الإنجليزية القادمة من مايكروتك إلى كلمات عربية واضحة:
   ```javascript
   document.getElementById("timeLeft").innerHTML = "$(session-time-left)"
       .replace("w", " أسبوع , ")
       .replace("d", " يوم , ")
       .replace("h", " ساعة , ")
       .replace("m", " دقيقة , ")
       .replace("s", " ثانية");
   ```
4. **دالة تحويل البايتات (`readablizeBytes`)**:
   دالة حسابية برمجية لتحويل البايتات إلى (بايت، كيلوبايت، ميجابايت، جيجابايت، تيرابايت).

## ⚠️ 7. نظام معالجة وترجمة الأخطاء (Error Localization Engine)

يحتوي القالب على نظام متطور مزدوج لترجمة رسائل أخطاء مايكروتك إلى لهجة ورسائل عربية ودية ومفهومة للمستخدم العادي:

### 1️⃣ نظام الجافاسكريبت داخل `login.html`:
```javascript
var error = "$(error)";
if (error == "simultaneous session limit reached") {
    document.write("ما تعرف تشبك اكتر من مرة"); // تجاوز عدد الأجهزة المسموحة
} else if (error == "invalid username or password") {
    document.write("غلط في رمز الدخول"); // خطأ في بيانات الكرت
} else if (error == "access denied at this time") {
    document.write("بطاقة سهرة لا يمكن استخدامها في هذا الوقت"); // باقات محددة بوقت
} else if (error == "uptime limit reached") {
    document.write("عذراً لقد انتهى الوقت المتاح لك.."); // نفاد الوقت
} else if (error == "invalid password") {
    document.write("كلمة المرور غلط");
} else if (error == "no more sessions are allowed for user $(username)") {
    document.write("ما بتحسن تشبك اكتر من مرة");
} else if (error == "no valid profile found") {
    document.write("البطاقة منتهية او غير صالحة راجع صاحب الشبكة");
} else if (error == "transfer limit reached" || error == "user $(username) has reached traffic limit") {
    document.write("رصيدك خلص. روح عبي عالسريع "); // نفاد رصيد البيانات (جيجابايت)
} else if (error == "user $(username) is not allowed to log in from this MAC address") {
    document.write("هذا الحساب خاص بجهاز اخر "); // كرت مقيد بماك أدرس
} else if (error.search("not found") != -1) {
    document.write("رمز الدخول غير موجود");
} else if (error == "invalid Calling-Station-Id") {
    document.write("رمز الدخول خاص بجهاز اخر لايمكن استخدامة في جهازك");
} else if (error == "radius timeout") {
    document.write("عزيزي المشترك نعتذر عن انقطاع الخدمة بسبب الصيانة سيتم اعادة الخدمة خلال دقائق");
} else {
    document.write("$(error)<br />");
}
```

### 2️⃣ ملف الترجمة من جهة السيرفر (`errors.txt`):
يوفر الترجمة الافتراضية التي يقرأها مايكروتك مباشرة في حال تعذر تشغيل الجافاسكريبت في متصفح العميل.

## 🚀 9. دليل التركيب والتشغيل على راوتر مايكروتك (Installation Guide)

1. **نسخ المجلد إلى الراوتر**:
   - افتح برنامج **Winbox** واتصل بالراوتر.
   - توجه إلى قائمة **Files**.
   - اسحب مجلد `soma` وأفلته في نافذة الملفات (Root directory أو داخل الـ flash).
   
2. **تحديد مجلد القالب في سيرفر الهوتسبوت**:
   - توجه إلى: `IP` -> `Hotspot` -> تبويب `Server Profiles`.
   - افتح البروفايل الخاص بسيرفرك (مثال: `hsprof1`).
   - في خانة **HTML Directory**، اختر مجلد `soma`.

3. **ضبط إعدادات الدخول الموصى بها في السيرفر (Login Methods)**:
   - في نفس نافذة الـ `Server Profile` -> تبويب `Login`:
     - قم بتفعيل: **HTTP CHAP** (لتفعيل التشفير مع md5.js).
     - قم بتفعيل: **HTTP PAP** (للتوافق مع الأجهزة البسيطة).
     - قم بتفعيل: **MAC** و **Cookie** (إن كنت ترغب بالحفظ التلقائي لجلسات المستخدمين).

4. **السماح بالملفات والروابط في Walled Garden (اختياري)**:
   - في حال رغبت بالسماح بروابط صفحات التواصل الاجتماعي (فيسبوك، تلجرام) قبل الدخول، قم بإضافتها في:
     `IP` -> `Hotspot` -> `Walled Garden`.
